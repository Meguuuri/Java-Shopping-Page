# MP4_CalipesCortezDizon - NetBeans 12.4 Ant Web App (Java EE 5 / GlassFish 2.x)
1. File > Open Project > select the `MP4_CalipesCortezDizon` folder (NetBeans generates build-impl.xml on first open).
2. Resolve the server problem by registering GlassFish 2 and selecting it in Project Properties > Run.
3. Source/target 1.6: no diamond, lambdas, try-with-resources, String switch.
4. Run: http://localhost:8080/MP4_CalipesCortezDizon/
5. Search the project for "TODO" to find everything left to fill in.
